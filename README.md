# learning-archive

Exercises and early projects from 2022–2023, from university courses and my first steps in Java, Hadoop, Python and web development.
Each folder was a separate repository. It was merged here with `git subtree`, so the full commit history is kept.

| Folder | What it is |
|---|---|
| `hadoop-mapreduce/Acnes-probability` | Acne probability from a dataset with Hadoop MapReduce |
| `hadoop-mapreduce/DNAs-symbols` | Splitting DNA symbols with MapReduce |
| `hadoop-mapreduce/Numeronyms-count` | Numeronym counting with MapReduce |
| `hadoop-mapreduce/IMDB-dateset` | IMDB data processing with MapReduce |
| `java-concurrency/words-counter` | Word counter with threads |
| `java-concurrency/Simpsons-` | Thread exercises |
| `java-concurrency/ProcessThread` | Processes & threads |
| `java-concurrency/tcpSocket` | TCP server–client connection |
| `Java-Exercises` | Java exercises with solutions |
| `Python` | Python mini projects |
| `Econometrica2` | Spring project |
| `myNextDrink` | A web page about drinks and cocktails |
| `pagies` | Printing bank order forms (PHP) |
| `yfantidis.net` | My old personal website |
| `Vaccination_Platform_Greek` | Greek vaccination platform (HTML) |

For current work, see my [profile](https://github.com/gyfantidis).
